图片整理  ImageSorter   v1.0.0
================================

把散在各处的图片和视频按拍摄时间分到月份文件夹里，文件名直接用拍摄时间。

作者：内战狂热爱好者
许可：MIT（全文见 LICENSE）


怎么运行
--------

双击 ImageSorter.exe，不用装 Python。

第一次打开，上面两个框已经填好了：

  图片文件夹   ← 改成你要整理的目录
  输出到       ← 默认是程序旁边的「整理结果」

点「扫描并预览」，下面列出每个文件将要去哪里、会叫什么名字。
看完没问题，再点「开始整理」。


三步
----

1. 选图片文件夹
2. 扫描并预览
3. 开始整理

整理错了点「撤销上次」，文件搬回原位，这次生成的空文件夹一并清掉。


文件名怎么定
------------

默认用拍摄时间命名：

  IMG_0001.jpg  →  20210304_100000.jpg

同一秒拍的多张会重名，自动加 _001。不想改名就在高级设置里
关掉「按拍摄时间重命名文件」，保留相机给的原名。

已经放在月份文件夹里、但名字还不对的文件，会被就地改名，
不会被漏掉。名字已经是 20210304_100000 这种形态的才跳过。


时间从哪来
----------

按顺序找，找到就用：

  EXIF DateTimeOriginal    相机记录的拍摄时间
  EXIF DateTimeDigitized
  EXIF DateTime
  XMP CreateDate
  PNG Creation Time
  视频文件头 mvhd          mp4 / mov / m4v / 3gp / 3g2
  文件名里的日期           如 IMG_20191224_183000、mmexport1687654321000
  文件修改时间             最后兜底


支持的格式
----------

能直接读出拍摄时间的：

  图片  jpg  jpeg jpe jfif  png  webp  tif  tiff
        heic heif avif hif
        dng  cr2  nef  arw  orf  rw2  pef  srw
  视频  mp4  mov  m4v  3gp  3g2

能整理、但文件里没有可读时间的（靠文件名或文件时间）：

  图片  gif  bmp
  视频  avi  mkv  webm  wmv  flv

HEIC 和视频时间都是程序自己解析的，不用装别的东西。


重复文件
--------

内容完全相同的文件只留一张，保留拍摄时间最早的那张，其余的不留在
输出目录里：默认挪进 .imagesorter_undo/trash/时间戳/，撤销能把它们
放回原处。高级设置里可以改成直接删除，那种删了就恢复不了。

判断是逐字节比对，不看文件名也不看大小。先按大小分组，只有大小一样
的才算哈希，所以整库扫描不会因此变慢。


三种处理方式（高级设置里）
--------------------------

移动   整理完原位置不再保留
复制   源文件不动，多占一份空间
链接   只建硬链接，源文件不动也不占空间
       要求源和目标在同一个磁盘、文件系统支持硬链接
       （NTFS 可以，FAT32/exFAT 不行，不支持时自动改复制）

「整理后删掉变空的文件夹」适合收拾相机卡。只删这次整理弄空的目录，
里面还有别的东西的不动。


几个要注意的
------------

- 扫描阶段只读文件，不动任何东西
- 默认不覆盖同名文件，重名会加 _001
- 输出位置已经有内容完全一样的文件时直接跳过，不会多出一份
- 一个文件出错不影响其他文件，失败项单独列在日志里
- 0 字节的文件和读不到的文件会跳过，在预览里标出来


常见问题
--------

Q  整理完发现文件没动？
A  先看预览表里「放到哪里」那一列和状态栏的数字。常见原因：
   已经在正确的月份目录且名字也对 → 标成「已在月份文件夹里」；
   内容和其他文件完全相同 → 标成重复，进了隔离区。

Q  时间不对？
A  相机时钟设错会写进 EXIF，只能手动改。先整理一遍，再单独处理那几张。

Q  iPhone 的 HEIC 或视频读不到时间？
A  标准容器都能读。个别改过封装的会退到文件名或修改时间，日志里
   「日期来源」那列会写实际用了哪一条。

Q  整理到一半断电了？
A  已经搬走的不受影响，重新扫描接着来，重复的会被认作已在正确位置。

Q  能选整个 C 盘吗？
A  可以，但系统壁纸、程序图标也会被搬走。建议只选放照片和视频的目录。


命令行
------

  python cli.py --source "D:\素材"                 只预览，不动文件
  python cli.py --source "D:\素材" --apply         真的整理
  python cli.py --source "D:\素材" --mode copy --apply
  python cli.py --source "D:\素材" --undo-latest   撤销最近一次
  python cli.py --help                             全部参数
